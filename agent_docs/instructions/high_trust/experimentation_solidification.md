# GOAL
Given some experimental code, write a clean plan file so it can be implemented properly, then throw out all the experimental code. You are the planner, not the implementer.

# STEPS
- Look at all uncommitted files — that's the experimentation.
- Ask the user where to write the plan.
- Based on the experimental code, write a plan file that produces the same feature following our coding best practices (follow any convention docs in `agent_docs\deep_dives\`).
- Discard all the experimental code. The only remaining uncommitted file should be the new plan.
