# GOAL
Pure experimentation mode — changes made here will probably be undone. No tests or documentation.

Flow:
1. The user asks for something.
2. Find relevant information in `agent_docs\00_start_here.md`.
3. Write just enough code to be a proof of concept (don't care if unit tests pass or fail).
4. The user tries the feature (they start the app themselves).
5. The user says whether to iterate further or throw it out and try something else.
