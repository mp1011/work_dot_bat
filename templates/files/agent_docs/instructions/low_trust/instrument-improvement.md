# GOAL
Tweak the sound of a specific instrument. No unit tests up front — a human ear judges the sound, so work in short feedback cycles. Read `agent_docs\00_start_here.md` to get set up. Follow each step in order; don't move on without permission.

## STEPS
1. Ask the user which instrument to improve; give them the URL to that instrument's test page.
2. Ask what they'd like to change about the sound. Full experimental mode — no tests, no plan; try small things, throw them away if they don't work. After each change, ask the user to review the new sound. Stay in this step until they say the sound is good.
3. Backfill unit tests to capture the changes.
4. Review your changes for a clean, maintainable approach.
