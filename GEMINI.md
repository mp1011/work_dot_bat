# GEMINI.md

This file provides system instructions and rules for Gemini and Antigravity agents working in this repository.

Read `agent_docs/00_start_here.md` — the **Critical Rules** and the **Session Startup Protocol** sections only. Route your task through its **Task Quick Reference** table, and read the specialized guides and any deep dive strictly on demand for a specific task — never as onboarding.

## Critical Rules
- **NEVER start the dev server.** Starting and managing the development server ((none configured)) is ALWAYS the user's responsibility.
- **NEVER commit (`git commit`) or push (`git push`) changes to git.**
- Do not run `git commit`, `git push`, or any variations that commit code or push to remote repositories.
- All git commits and pushing to remote repositories must be performed manually by the user.
